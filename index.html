Discord Music Bot

Discord Music Bot made with discord developer portal. The bot takes a prefix command + a youtube link and plays the song linked in any channel as long as user is in voice channel. The bot was programmed in Java and uses Discords wrapper JDA. Discord bot is available on github.

Slack Bot

Simple slack robot made using Cloudflares workers and Cloudflares Wrangler CLI. The bot was written in java script. Bot makes use of GitHub webhooks to send messages to a Slack channel when issues are updated or created, and allow users to write a command to look up GitHub issues from inside Slack. The bot is hosted serverless and able to be summoned 24/7. Summoned by using this syntax, /issue owner/repo#issue_number.
